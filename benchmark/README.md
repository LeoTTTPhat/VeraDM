# Verifiable Discovery Benchmark

This directory packages the public VeraDM benchmark artifact. The goal is
to evaluate systems that propose natural-language data-mining hypotheses and
then verify them with reproducible evidence cards.

## Tasks

The benchmark has four tracks:

1. **Synthetic failure matrix**: known support, FDR, contrast, permutation, and
   held-out failure regimes.
2. **Semi-synthetic real-data injection**: known true and null rules injected
   into real covariates.
3. **Temporal case studies**: Bank Marketing and Bike Sharing discovery with
   future-period replication.
4. **Auditability**: evidence-card completeness and reproducibility checks.

## Submission Format

Submit a CSV with one row per proposed claim:

```text
dataset,run_id,claim,compiled_query,decision,p_value,q_value,
validation_effect,heldout_effect,contrast_effect,support_validation,
support_holdout,rejection_reason,evidence_card_json
```

Claims may be generated by an LLM, a human analyst, a classical pattern miner, or
a hybrid system. The leaderboard evaluates the final accepted/rejected evidence
cards, not the source of the proposal.

## Leaderboard Metrics

- `injected_recall`: recall on known injected true rules.
- `empirical_fdr`: false discoveries among accepted known-null or shifted rules.
- `replication_survival`: validation-accepted claims that survive future-period
  held-out replication.
- `compile_success`: fraction of proposed natural-language claims that compile.
- `evidence_completeness`: fraction of cards reporting query, support, effect,
  adjusted significance, contrast, held-out effect, interval, and reason.
- `redundancy_after_pruning`: accepted-rule coverage overlap after pruning.

## Reproducing the Current Baseline

From the repository root:

```bash
python3 experiments/run_synthetic_failure_matrix.py
python3 experiments/run_real_injection_benchmark.py
python3 experiments/run_temporal_case_study.py
python3 experiments/run_bike_sharing_case.py
python3 experiments/run_context_assumption_study.py
python3 experiments/export_verifiable_tables.py
```

The generated CSVs in `results/` are the initial baseline submission.
